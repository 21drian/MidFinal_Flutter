# ScoreMind

A Flutter-based student grade and task monitoring app with Firebase Authentication, Firestore TODO storage, SQLite local TODO storage, mock instructor API data, dashboard, grades, tasks, and profile features.

## Features

- Student login and registration using Firebase Authentication
- Dashboard with student overview and academic summary
- Read-only grades using mock instructor API data
- TODO task management with create, read, update, and delete features
- Firebase Firestore storage for online TODO data
- SQLite local storage for offline/local TODO backup
- Profile screen with student information and logout
- Mobile-friendly Flutter UI
